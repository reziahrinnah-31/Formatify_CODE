# Formatify_CODE

An academic document formatting web application that helps students format project reports and academic documents using predefined templates.

## Features

- Academic document formatting
- Predefined document templates
- Student dashboard
- Template management

## Technology Stack

- React
- Vite
- JavaScript
- CSS

## How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install the dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL shown in your terminal.
